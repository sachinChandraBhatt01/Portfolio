# Sachin Chandra Bhatt, portfolio

Open `index.html` in a browser to preview. Upload the whole folder to host it (Netlify Drop, GitHub Pages or any hosting).

## Before you publish (2 minutes)
1. Open `script.js` and fill in the `CONFIG` block at the top:
   - `whatsapp`: country code + number, digits only (for example `919876543210`). Do not use `+`, spaces or dashes.
   - `github` and `linkedin`: your real profile links.
2. Contact: every contact button and the form use WhatsApp only.
   - The form collects name, service and message, then opens WhatsApp with the message ready to send to your number. It works from a file on your computer too, so you can test it right away.
   - There is no email, no server and no sign-up to maintain.

## Folders
- `projects/estateease` and `projects/studiomitti`: the two website demos, shown live on the page.
- `data.js`: the 500 sample orders behind the RetailPulse dashboard.
- `assets/`: the screenshot of the original Excel dashboard.
