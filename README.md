# Sachin Chandra Bhatt, portfolio

Open `index.html` in a browser to preview. Upload the whole folder to host it (Netlify Drop, GitHub Pages or any hosting).

## Before you publish (5 minutes)
1. Open `script.js` and fill in the `CONFIG` block at the top: your real email, WhatsApp number (country code + number, digits only), GitHub and LinkedIn links.
2. Contact form: it sends messages to `CONFIG.email` through FormSubmit, with no key needed.
   - After the site is online, send one test message from the form.
   - FormSubmit emails you a one-time "Activate form" link. Click it, and every later message arrives in your inbox.
   - The form does not send from a file opened on your computer. Test it on the hosted site.
   - Prefer Web3Forms? Get a free key at web3forms.com and paste it into `formKey`.
